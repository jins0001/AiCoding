지표 하나를 라벨, 값, 단위, 증감, 스파크라인으로 보여 주는 타일입니다. 값은 `metric` 스타일의 mono로, 자릿수가 세로로 맞습니다.

## 사용할 때

- 학습 실행 페이지 상단에 손실, 정확도, 학습률, 자원 순으로 넷까지.
- 평가 요약에서 핵심 지표 하나를 크게 보여 줄 때.

## 소비자가 제공하는 것

- `label`과 서식을 마친 `value`. 타일은 숫자를 반올림하지 않습니다. 손실과 정확도는 소수 4자리, 학습률은 `1e-4`, 메모리는 `11.2`에 `unit: 'GB'`.
- `delta`는 부호를 포함한 문자열(`+0.0333`), `deltaTone`은 소비자가 판단합니다. 손실은 내려가야 좋으므로 `-0.0124`에 `good`을 넘깁니다.
- `series`: 최근 값 배열. 축 없이 `series-1` 색으로 추세만 그립니다.
- `note`: 기준 시점이나 비교 대상 한 줄("검증 세트, epoch 5").

## 하기 / 하지 않기

- 타일 하나에 지표 하나. 두 값을 비교하려면 타일을 둘 놓습니다.
- 값이 없으면 `value`를 비워 두면 대시(—)로 그려집니다. `0`을 넣지 않습니다.
