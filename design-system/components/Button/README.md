동작 하나를 담는 버튼입니다. 라벨은 한국어 동사구("학습 시작", "체크포인트 저장")로 쓰고, 화면에 `primary`는 하나만 둡니다.

## 사용할 때

- `primary`: 화면의 주 동작. 학습 시작, 체인 실행, 저장.
- `secondary`(기본): 주 동작 옆의 보조 동작. 체크포인트 저장, 설정 열기.
- `ghost`: 표나 카드 안의 인라인 동작. 로그 보기, 복사.
- `danger`: 되돌릴 수 없는 동작. 실행 중지, 체크포인트 삭제. 반드시 확인 단계를 둡니다.

## 소비자가 제공하는 것

- `label`(필수)과 `onClick`.
- `glyph`: 라벨 앞의 mono 글리프 하나(▶ ■ ✓). 이모지는 쓰지 않습니다.
- `size`: `sm` 28px(표 안), `md` 32px(기본), `lg` 40px(페이지 상단의 주 동작).
- `loading`: 스피너를 더하고 비활성화합니다. 라벨은 그대로 둡니다.

## 하기 / 하지 않기

- 라벨은 2~6글자의 동사구로. "확인", "예" 같은 모호한 라벨 대신 "학습 시작".
- 비활성 버튼 옆에는 이유를 `caption`으로 적습니다.
- `danger`를 채움으로 쓰지 않습니다. 테두리와 글자만 `danger`입니다.
