하이퍼파라미터 하나를 입력하는 필드입니다. 한국어 라벨과 코드가 쓰는 이름(`learning_rate`)을 나란히 보여 주고, 값은 `code-sm` 스타일의 mono로 받습니다.

## 사용할 때

- 파인튜닝 설정 폼: 학습률, 에포크, 배치 크기, LoRA rank, 베이스 모델.
- 체인 노드의 속성 패널: `temperature`, `k`, `max_tokens`.
- 끝난 실행의 설정 요약(`disabled`로).

## 소비자가 제공하는 것

- `label`(한국어)과 `name`(코드 이름). 둘 다 주면 라벨 줄 오른쪽에 `name`이 mono로 섭니다.
- `kind`: `text`, `number`, `select`. `number`는 숫자 키패드를 띄우되 `1e-4` 같은 지수 표기가 입력되도록 텍스트 입력으로 그립니다. 검증은 소비자가 합니다.
- `unit`: 값 뒤의 단위(`steps`, `GB`, `%`).
- `hint` 또는 `error`: 필드 아래 한 줄. `error`가 있으면 테두리와 글자가 `danger`로 바뀌고 `aria-invalid`가 붙습니다.
- `options`: `select`의 선택지. 문자열이나 `{ value, label }`.

## 하기 / 하지 않기

- 라벨은 명사구 2~5글자("학습률", "배치 크기"). 문장으로 쓰지 않습니다.
- 기본값이 있으면 `placeholder`가 아니라 `value`로 채웁니다. 플레이스홀더는 형식 예시(`예: 1e-4`)에만.
- 오류는 무엇이 잘못됐고 어떤 값이 되는지 한 문장: "2의 거듭제곱이어야 합니다."
