노트북 셀입니다. 왼쪽 `gutter` 폭의 거터에 `In [n]:`과 `Out [n]:`이 서고, 코드는 `surface-200` 위에 `code` 스타일로, 출력은 그 아래 `ink-700`으로 놓입니다. `kind: 'prompt'`면 프롬프트 템플릿으로 바뀌어 `{변수}`가 `highlight`로 강조됩니다.

## 사용할 때

- 노트북 뷰에서 코드와 출력을 함께 보여 줄 때.
- 프롬프트 템플릿을 편집하거나 검토할 때(`kind: 'prompt'`).
- 문서 안에서 실행 가능한 예제를 보여 줄 때(`output` 없이).

## 소비자가 제공하는 것

- `code`(필수): 원문 그대로. 셀이 파이썬 키워드, 문자열, 숫자, 주석을 `code-*` 토큰으로 칠합니다. 들여쓰기는 보존됩니다.
- `index`: 실행 번호. `status: 'running'`이면 거터가 `In [*]:`이 되고 `primary` 색을 띱니다.
- `output`: 출력 문자열 그대로. `status: 'error'`면 `danger` 글자로.
- `title`과 `lang`: 셀 위의 머리줄. "1. 데이터 준비"와 `python`처럼.

## 하기 / 하지 않기

- 출력을 요약하거나 자르지 않습니다. 길면 셀이 자랍니다.
- 프롬프트 변수 이름은 코드의 것과 같아야 합니다(`{context}`, `{question}`). 셀은 이름을 바꾸지 않습니다.
- 한 셀에 한 단계. 데이터 준비와 학습을 한 셀에 넣지 않습니다.
