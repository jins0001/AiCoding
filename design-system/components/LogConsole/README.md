학습 루프나 체인 실행이 남기는 로그를 타임스탬프, 레벨, 메시지의 줄로 보여 주는 콘솔입니다. 바탕은 `surface-200`, 글자는 `log` 스타일의 mono입니다.

## 사용할 때

- 학습 실행 페이지의 맨 아래, 진행 막대 다음.
- 체인 캔버스에서 실패한 노드를 골랐을 때 그 노드의 로그.

## 소비자가 제공하는 것

- `lines`: `{ t, level, msg }` 배열. `t`는 `hh:mm:ss`, `level`은 `DEBUG`/`INFO`/`WARN`/`ERROR`. `msg`는 코드가 출력한 문장 그대로입니다.
- `title`: 소스 이름(`train.py`, `chain run #18`). `status`를 주면 머리글 오른쪽에 StatusChip이 붙습니다.
- `height`: 본문 최대 높이(px). 넘치면 스크롤되고, `follow`가 켜져 있으면 마지막 줄로 내려갑니다.

## 레벨의 색

`DEBUG` `ink-500`, `INFO` `ink-700`, `WARN` 레벨 글자만 `warning`, `ERROR` 줄 전체가 `danger`. 바탕은 칠하지 않습니다.

## 하기 / 하지 않기

- 줄을 자르거나 바꾸지 않습니다. 긴 줄은 가로로 스크롤됩니다.
- 로그 안에서 지표를 강조하지 않습니다. 강조할 값은 MetricTile로 올립니다.
