에포크와 스텝의 진행을 한 줄의 막대로 보여 줍니다. 막대는 에포크 수만큼 칸으로 나뉘어, 몇 번째 에포크의 어디쯤인지가 숫자 없이도 읽힙니다.

## 사용할 때

- 학습 실행 페이지에서 지표 타일 아래, 로그 콘솔 위.
- 실행 목록의 행 안에서 축약형으로(`loss`, `eta` 없이).

## 소비자가 제공하는 것

- `epoch`(1부터), `epochs`, `step`, `steps`. 진행률은 `(epoch - 1 + step / steps) / epochs`로 계산됩니다.
- `status`: `running`이면 `primary`, `succeeded`면 `success`, `failed`면 `danger`, `stopped`면 `ink-500`으로 채웁니다.
- `loss`, `acc`, `lr`, `eta`: 서식을 마친 문자열. 막대 아래 mono 한 줄로 놓입니다.

## 하기 / 하지 않기

- 에포크가 50을 넘으면 칸을 나누지 않고 한 칸으로 그립니다.
- 진행률 퍼센트는 완료된 뒤에만 보여 줍니다. 실행 중에는 `step n / N`이 더 정확합니다.
- 두 실행을 비교하려면 막대를 세로로 쌓습니다. 한 막대에 두 실행을 겹치지 않습니다.
