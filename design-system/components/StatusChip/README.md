실행(run)의 상태를 단어와 표식으로 보여 주는 칩입니다. 상태는 여섯 가지뿐이며 칩, 로그, 노드, 표에서 같은 단어를 씁니다.

## 상태

| status | 단어 | 표식 | 색 |
| --- | --- | --- | --- |
| `queued` | 대기 | 빈 원 | `ink-700` / `surface-300` |
| `running` | 실행 중 | 맥동하는 점 | `primary` / `primary-soft` |
| `succeeded` | 완료 | ✓ | `success` / `success-soft` |
| `failed` | 실패 | ✕ | `danger` / `danger-soft` |
| `stopped` | 중지 | 네모 | `ink-700` / `surface-300` |
| `draft` | 초안 | 점선 원 | `ink-500`, 점선 테두리 |

## 소비자가 제공하는 것

- `status`(필수). 모르는 값은 `queued`로 그려집니다.
- `label`: 단어를 바꿀 때만("검증 중"). `lang: 'en'`이면 영문 단어.

## 하기 / 하지 않기

- 색만으로 완료와 실패를 구분하지 않습니다. 글리프와 단어가 항상 따라옵니다.
- 칩을 버튼으로 쓰지 않습니다. 상태를 바꾸는 동작은 Button입니다.
- 한 행에 칩은 하나. 여러 속성은 표의 열로 풉니다.
